# 입력 유형별 오류 문구

화면은 입력 오류가 생기면 이전 QR을 숨기고 QR 저장을 비활성화합니다.

| 유형 | 조건 | 표시 문구 |
| --- | --- | --- |
| URL | 빈 값 | 웹 주소를 입력해 주세요. |
| URL | http/https 누락 | 주소 앞에 http:// 또는 https://를 포함해 주세요. |
| URL | 잘못된 주소 | 올바른 웹 주소를 입력해 주세요. |
| Wi-Fi | 네트워크 이름 누락 | 네트워크 이름을 입력해 주세요. |
| Wi-Fi | 비밀번호 사용인데 비밀번호 누락 | 비밀번호를 입력해 주세요. |
| Wi-Fi | 줄바꿈·제어 문자 | 네트워크 이름과 비밀번호에는 줄바꿈을 넣을 수 없어요. |
| 연락처 | 성·이름 모두 누락 | 성과 이름 중 하나는 입력해 주세요. |
| 연락처 | 이메일 형식 오류 | 올바른 이메일 주소를 입력해 주세요. |
| 연락처 | 웹사이트 주소 오류 | 웹사이트 주소는 http:// 또는 https://로 시작해야 해요. |
| 텍스트 | 빈 값 또는 공백만 입력 | 내용을 입력해 주세요. |
| 텍스트 | QR 용량 초과 | 내용이 너무 길어요. 조금 줄여 다시 시도해 주세요. |
| 이메일 | 받는 주소 누락 | 받는 주소를 입력해 주세요. |
| 이메일 | 받는 주소 형식 오류 | 올바른 이메일 주소를 입력해 주세요. |

공통 생성 실패: QR을 만들지 못했어요. 내용을 확인하고 다시 시도해 주세요.
공통 다운로드 실패: 파일을 저장하지 못했어요. 다시 시도해 주세요.
