## 설계와 시안 비교

2026-10-10 사용자가 비로그인 직접 다운로드를 추가하도록 설계를 변경했다. ‘일회용’의 의미는 계정에 저장하지 않고 PNG/SVG를 바로 다운로드하는 것으로 확인했다. 다운로드한 QR은 여러 번 스캔할 수 있다. 기존의 모든 다운로드에 로그인·저장을 요구하는 규칙을 설계안·AGENTS·README·로컬 SVG에서 변경했다. 로그인 사용자의 계정 보관, 내 QR 다운로드 형식 선택, QR 삭제 확인은 유지한다.

원본 시안에 없는 상태는 QR 용량 초과/생성 실패, 저장 실패, 다운로드 실패다. 사용자가 2026-10-10 보완 UI의 결정을 위임하여 `docs/설계안.md`의 `시안 보완 확정 UI` 절에 표시 위치·정확한 문구·재시도 동작을 확정하고 로컬 SVG 수정본에 반영했다. 추가 승인 없이 해당 기준으로 구현한다. 웹앱 화면 구현은 아직이다.

원본 와이파이 정상 화면에는 비밀번호 필드가 있지만 보기/가리기 버튼 또는 아이콘이 없다. 수정본은 입력칸 오른쪽의 `보기`/`가리기` 버튼과 비밀번호가 보이는 별도 상태를 포함한다. 공개 네트워크 전환과 유형 이동 후에는 보기 상태를 해제하고, 기존 비밀번호를 복원할 때 가린다. 전환 동작은 정적 SVG가 아니라 웹앱 구현 단계에서 검사한다.

PDF는 계정/서버 저장을 제외하고 모바일을 포함하는 이전 기획이다. 사용자가 확정한 흐름 및 AGENTS.md가 지정한 설계안을 구현 기준으로 삼는다.

설계에 있는 세부 동작 중 정적 시안만으로 확인할 수 없는 것: 로그인 팝업의 입력 유지, 와이파이 비밀번호 보기/가리기와 공개 네트워크 전환 후 복원, 키보드/보조 기술 동작, CSRF/PKCE, 암호화 및 소유권 검사, 실제 QR 스캔. 정적 화면에 보인다고 구현된 기능으로 간주하지 않는다.

## 구현 순서

1. URL 검증 및 공통 QR 생성 모듈: 원문 보존, 검정/흰색 SVG, 4모듈 여백, 실제 디코딩 검사.
2. React/TypeScript/Vite 데스크톱 URL 입력·미리보기와 비로그인 PNG/SVG 다운로드: CSS Modules/변수, 정상/오류 문구, 유효하지 않은 입력에서 이전 QR 제거와 다운로드 차단, 파일 디코딩 검사. 로그인 안내와 비로그인 진입을 제공한다. 계정 저장/로그인은 서버 연결 전까지 완료로 표시하지 않는다.
3. 와이파이·연락처·텍스트·이메일 페이로드와 폼: 유형별 오류, 메모리에서 입력 유지, 스캔 검증.
4. Java 21/Spring Boot/Gradle, PostgreSQL/Flyway, GitHub OAuth2 세션 인증 및 CSRF/PKCE. 암호화 저장, 사용자별 소유권 검증, 내 QR 목록.
5. 저장된 페이로드에서 PNG 1024×1024/SVG 재생성, 다운로드 형식 선택, QR 삭제 확인. 실제 로그인/계정 격리/저장/재다운로드/삭제와 Android·iOS 기기 검증.
