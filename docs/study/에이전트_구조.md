# 에이전트 구조 검토 메모

## 현재 채택한 저장소 구조

```text
qr_생성/
├─ AGENTS.md              # 저장소 공통 지침
├─ src/                   # 웹페이지 코드
├─ tests/                 # 테스트와 입력 사례
├─ docs/설계안.md          # 제품 설계
├─ .agents/skills/         # 자동 발견용 반복 작업 절차
└─ harness/skills/         # Figma 로컬 SVG 작업 규칙
```

제품 코드와 검사는 저장소 루트에 두고, 에이전트 지침과 반복 작업 절차를 구분한다.

현재 Figma 시안 작업 규칙은 `harness/skills/figma-local-svg/SKILL.md`에 두고 루트 `AGENTS.md`에서 연결한다. 화면 시안은 로컬 SVG로 만든 뒤 사용자가 Figma에 붙여넣는다.

## 초기 구상: 역할별 지침 파일

```text
harness/
└─ agents/
   ├─ planner.md       # 설계안을 작업 단위와 완료 기준으로 나눔
   ├─ implementer.md   # 지정된 기능을 구현하고 관련 검사를 실행
   └─ verifier.md      # 설계안과 결과를 대조하고 근거를 보고
```

각 역할 파일에는 맡는 일, 읽을 자료, 수정 가능한 범위, 제출할 결과, 완료 기준을 적는다. `verifier`는 우선 결과만 보고하고 수정은 하지 않는다. 화면 시안 역할은 보류한다.

`harness/agents/*.md` 파일을 만든다고 에이전트가 자동으로 실행되지는 않는다. 역할 파일은 작업할 때 명시적으로 지정하거나, 나중에 `AGENTS.md`에서 연결해야 한다. Codex가 자동으로 읽는 `AGENTS.md`와 역할 파일의 용도는 다르다.

이 역할 파일은 아직 만들지 않았다. 이후 역할별 지침이 실제로 필요해지면 실행 방식과 연결 방법을 먼저 정한다.
