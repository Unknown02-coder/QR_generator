# QR 웹 퍼블리싱 구현 계획

**목표:** 확정한 데스크톱 시안을 React 화면으로 옮기고, 입력·미리보기·저장 및 내 QR 관리 화면의 사용자 동작을 연결한다.

**기준:** `docs/설계안.md`, `output/QR_생성_전체_화면시안_Figma_붙여넣기.svg`, `AGENTS.md`.

## 화면과 코드

1. Vite·React·TypeScript 기본 구조와 CSS 변수, 공통 화면 레이아웃을 만든다.
2. 다섯 입력 유형의 폼, 필드별 오류, 탭별 값 유지, QR 미리보기를 만든다. URL·Wi-Fi 변환기는 기존 모듈을 사용하고 나머지 세 유형을 별도 모듈로 만든다.
3. 로그인·저장·다운로드 형식 선택·삭제 확인·실패 대화상자를 만든다. 인증 및 저장 호출은 서버 API 경계에서 처리한다.
4. `내 QR` 목록, 유형 필터, 5개 단위 페이지네이션, 빈 목록을 만든다. 민감한 QR 내용은 목록 요약에 넣지 않는다.
5. 빌드와 페이로드 검사, 브라우저 화면 확인으로 완료 여부를 판단한다.

## 이번 범위의 한계

현재 저장소에는 Spring Boot 서버가 없다. GitHub OAuth, 암호화 저장, 사용자별 접근 제어 및 실제 재다운로드는 이 프론트엔드만으로 완료할 수 없다. 서버 호출 부분은 연결 지점을 명확하게 두고, 서버가 없을 때 성공한 것처럼 표시하지 않는다.

원본 Figma에는 예전 비로그인 다운로드 화면이 남아 있다. 실제 화면 흐름은 확정된 `AGENTS.md`와 설계안의 저장 후 다운로드를 따른다.
